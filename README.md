# South Dakota vendor checkbook data

This repository is archived. South Dakota's vendor checkbook data (state payments to vendors, from July 2020 on) is published as one Parquet file per fiscal year at [south-dakota-citizen-archivist/sd-archive › releases › Vendor checkbook data](https://github.com/south-dakota-citizen-archivist/sd-archive/releases/tag/vendor-checkbook-data).

The monthly CSV files here cover July 1, 2020, to November 6, 2026. They keep every version of a row collected while its year was published, so a payment the state later revised (most often a renamed vendor) can appear more than once.
